# 📝 Todo List App

A simple and responsive Todo List web application built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📱 Responsive design
- 🎨 Clean and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
